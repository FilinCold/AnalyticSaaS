# NON_GOALS — что не делаем

## Антипозиционирование продукта

- Product analytics / GA / Amplitude / трекинг поведения в чужом продукте.
- Универсальная «платформа идей для любого бизнеса» без фильтров micro-SaaS.

## Вне scope рекомендуемых идей (всегда)

- CRM, ERP, экосистемы, сервисы «для всего бизнеса».
- Идеи с One Job < 80, AI Buildability < 75, days > 14, First Sale < 70 — в основной список.
- Идеи, требующие команду / сильный fullstack / DevOps / отдельного дизайнера / sales как условие сборки.

## Вне MVP AnalyticSaaS (post-MVP или никогда без нового ТЗ)

- Биллинг / подписки / тарифы AnalyticSaaS.
- Организации, роли, команды, SSO.
- Авто-адаптеры **сверх** HN + Product Hunt + Reddit + manual (доп. форумы — post-MVP, см. `OPEN_QUESTIONS`).
- Полноценный веб-краулер «всего интернета» (платформенная лента = только согласованные адаптеры, любые ниши **внутри** этих источников).
- Генерация кода / репозитория / деплоя найденного micro-SaaS.
- Конструктор лендингов, email-рассылки, авто-DM outreach.
- Встроенные платежи **для** найденного micro-SaaS (только рекомендация способа).
- UGC-маркетплейс / соцсеть «чужих» идей (не путать с **платформенной AI-лентой** — она в MVP).
- Обязательное создание Research пользователем как шаг happy path (Research — internal; см. `DECISIONS.md` 2026-07-30).
- Мобильные приложения.
- Real-time collaborative editing.
- Сложный A/B и эксперименты внутри AnalyticSaaS.
- Гарантия «идея заработает» / автозакуп рекламы.
- Высоконагруженный distributed scraping cluster.

## Недостаточное подтверждение спроса (не цель системы оптимизировать)

Лайки, комментарии, комплименты, подписки, «интерес» без действия — не целевые метрики успеха идей.
