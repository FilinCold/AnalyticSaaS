# VISION — AnalyticSaaS

## Окончательное назначение

**AnalyticSaaS** — AI-система поиска **коммерчески проверяемых** идей узких **micro-SaaS** для соло-создателя, который собирает продукт с помощью AI coding agent.

Система берёт сигналы из открытых источников (обсуждения, жалобы, отзывы, feature requests, конкуренты), **без обязательного выбора ниши пользователем**, превращает их в структурированные карточки идей и пропускает через жёсткие фильтры:

| Критерий | Порог |
|---|---|
| One Job Score | ≥ 80 |
| AI Buildability Score | ≥ 75 |
| estimatedBuildDays | ≤ 14 |
| First Sale Potential | ≥ 70 |

**Главный результат для пользователя:** актуальная **лента** отфильтрованных идей (как лента статей на новостном портале) вида  
«конкретный пользователь → конкретные данные → один результат», которые можно собрать за ≤14 дней соло+AI и быстро проверить реальными продажами. У каждой идеи — полная аналитика (скоры, build, sales, go/kill).

## One Job самой платформы AnalyticSaaS

> Соло-создатель заходит в продукт → видит обновляемую ленту ранжированных micro-SaaS-возможностей (любые ниши), прошедших все пороги, со сводной статистикой и карточкой с планом сборки и первой продажи.

_(Обновление ленты: каждые 3–5 дней; в MVP cron фиксирован на **3 календарных дня** — `DECISIONS.md` § 2026-07-30.)_

## Что это НЕ

- не product analytics (не GA / Amplitude / аналитика поведения в готовом продукте);
- не генератор кода / IDE / агент разработки найденного micro-SaaS;
- не CRM / ERP / «платформа для всего бизнеса»;
- не UGC-маркетплейс / соцсеть «чужих» идей (лента — результат AI-pipeline платформы).
