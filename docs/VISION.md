# VISION — AnalyticSaaS

## Окончательное назначение

**AnalyticSaaS** — AI-система поиска **коммерчески проверяемых** идей узких **micro-SaaS** для соло-создателя, который собирает продукт с помощью AI coding agent.

Система берёт сигналы из открытых источников (обсуждения, жалобы, отзывы, feature requests, конкуренты, ручные процессы), превращает их в структурированные карточки идей и пропускает через жёсткие фильтры:

| Критерий | Порог |
|---|---|
| One Job Score | ≥ 80 |
| AI Buildability Score | ≥ 75 |
| estimatedBuildDays | ≤ 14 |
| First Sale Potential | ≥ 70 |

**Главный результат для пользователя:** отфильтрованный список идей вида  
«конкретный пользователь → конкретные данные → один результат», которые можно собрать за ≤14 дней соло+AI и быстро проверить реальными продажами.

## One Job самой платформы AnalyticSaaS

> Соло-создатель задаёт нишу/тему → получает ранжированные карточки micro-SaaS-возможностей, прошедшие все пороги, с планом сборки и планом первой продажи.

## Что это НЕ

- не product analytics (не GA / Amplitude / аналитика поведения в готовом продукте);
- не генератор кода / IDE / агент разработки найденного micro-SaaS;
- не CRM / ERP / «платформа для всего бизнеса».
