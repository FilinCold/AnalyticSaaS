# USER_FLOWS — пользовательские сценарии MVP

## Актор

Соло-создатель (профиль Части 3).

## Flow A — Happy path (vertical slice)

1. Регистрация / вход.
2. Создаёт Research: тема + keywords.
3. Добавляет сигналы (paste) и/или запускает ingest одного адаптера.
4. **Первый раз:** pipeline стартует **автоматически** (если есть сигналы) — пользователь видит статус без обязательного клика.
5. Ждёт статус job (queued → running → **succeeded** / failed). UX: «Готово» / «Ошибка».
6. Открывает вкладку «Рекомендованные»: список по Opportunity Score.  
   _(Вкладки «Суженные» и «Исключённые» — см. Flow B/C.)_
7. Открывает карточку: one-job шаблон, скоры, build-блок, sales-блок, go/kill.
8. (Опционально) правит поля сужения → «Пересчитать скоры».
9. (Опционально) нажимает «Обновить идеи» для повторного сбора вне расписания.

## Flow A2 — Плановое обновление (раз в 3 дня)

1. Cron находит Research с `last_pipeline_finished_at` > 3 дней назад.
2. Автоматически: ingest (если настроен адаптер) → `pipeline.run` (`trigger=scheduled`).
3. Пользователь при входе видит обновлённый список и метку «Обновлено …» / статус последнего run.

## Flow B — Нет идей в основном списке

1–5 как в Flow A (шаг 4 — авто или manual).  
6. Основной список пуст; видит «Исключённые» с причинами (порог / не one-job / days / sales).  
7. Сужает Research или добавляет сигналы → повторный анализ.

## Flow C — Идея сужена системой

1. Во вкладке **«Суженные»** или в карточке статус `narrowed`: показаны `featuresExcludedToFitDeadline` и пересчитанные скоры.  
2. Пользователь принимает narrowed-версию (→ rescore может перевести в `recommended`) или исключает.

## Flow D — Pipeline завершился с ошибкой

1. Статус run = `failed`; пользователь видит краткое сообщение (без секретов/стека).  
2. Кнопка «Повторить анализ» → новый `pipeline.run` с `trigger=manual`.  
3. Предыдущие recommended сохраняются до успешного нового run (см. `BACKGROUND_JOBS.md` § Идемпотентность).

## Вне MVP flows

Оплата подписки AnalyticSaaS; шаринг идей; запуск AI-агента сборки из карточки.
